bkit을 한 장으로 소개하겠습니다. Claude Code에 설치하는 플러그인으로, AI가 만든 코드를 자기가 쓴 설계서와 대조해서 검증해 줍니다. 계획, 설계, 구현, 검수, 수정, 보고, 보관이 하나의 루프입니다. 핵심은 Check 단계입니다. 설계와 코드가 얼마나 일치하는지 점수로 매기고, 비용·보안·동시성 문제를 따로 분석합니다. 단계마다 "이 범위가 맞나요?", "설계안 셋 중 무엇?"처럼 사람에게 물어봐서, 저는 거의 "다음 진행"만 입력했습니다.
