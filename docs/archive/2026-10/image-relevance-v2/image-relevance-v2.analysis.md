| I-1 | `draftPipeline.ts` advancePost | 계획이 없는 IMAGES 단계가 남은 시간 20초로 시작될 수 있음(POLISH 직후). 계획 23~34초라 시간 초과 → C-1과 같은 멈춤 | 계획 없는 IMAGES는 120초 이상 남았을 때만 시작, 아니면 다음 실행에 넘김 |

| I-4 | `aiService.ts` scoreImage | 마지막 줄 "대상이 보이는지, 뜻과 맞는지만 봅니다"가 1점 사유(손·얼굴 왜곡, 읽히는 큰 글자)를 무시하게 할 수 있음. 대상이 화면 자체인 옛 계획은 흐린 화면만으로 4~5점 가능 → 점수 부풀리기 | 마지막 줄에 1점 사유 포함, 흐린 화면 감점 제외는 "대상이 화면 자체가 아닐 때"로 한정 |
| I-5 | `draftPipeline.ts` planImageSet | 겹침과 나열이 동시면 겹침 사유만 전달 → 다시 계획해도 나열 남을 수 있음 | 사유를 둘 다 전달 |

### 경미
- anchor에 ` / `가 없거나 한글이 없으면 영어 쉼표로 오탐, "TCP/IP 설정 / …"은 잘못 자름 → ` / `로 나누고 한글 없으면 false
- `replanScene` 결과에 prompt가 없으면 `similarity`·`stripStyleWords`에서 오류 → prompt 확인
- 주석: 토큰 범위 "5.5~6.5천" → "5.5~8.5천", 표지 제외 근거 §2.2 → §6
- 문서: 계획서의 `와/과` 감지 문구, FR 상태, 설계서 §8 번호
- 테스트 빈칸: 다시 계획 실패, `·` 복합어, `ㆍ`/`，`, 시간 부족
