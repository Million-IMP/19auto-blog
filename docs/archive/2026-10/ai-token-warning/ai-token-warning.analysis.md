### 경미
- OSMU가 글 없이 끝나면(생각만 하고 end_turn) 빈 초안이 저장됨 — 이전부터 있던 문제. askText처럼 "비어 있습니다" 오류
- 기록 DB 호출에 시간 제한 없음 → 2초 제한
- 채점 잘림 경로(자체 문구 + 경고 기록) 테스트 없음
- 9996/10000이 "100%"로 표시 → 내림
- `aiService.test.ts`가 실제 DB 클라이언트를 불러옴 → `../db` mock, 잘림 시 경고 기록도 확인
- 계획서 NFR "기다리지 않음" → 설계대로 "드문 경우라 기다림"
- 동시 호출 시 같은 날 2건 기록 가능 — 수용
- 직접 호출 3곳의 반복 코드를 askText로 합치기 — 이번 범위 밖(다음 정리 후보)
