# 19auto-blog

로컬에서 글을 모으고 초안을 만드는 화면입니다.

## 실행

1. 저장소를 복제합니다.
2. `backend/.env.example`을 `backend/.env`로 복사하고 Anthropic 키를 넣습니다.
3. 저장소 루트에서 아래를 실행합니다.

```
npm start
```

4. 브라우저에서 http://localhost:5173 을 엽니다.

키 외에 다른 값은 필요 없습니다. 데이터베이스 파일은 처음 실행할 때 만들어집니다. 모델 기본값은 `claude-haiku-5-5`입니다. 채널, 재료, 규칙은 화면에서 직접 추가합니다.
